# PaaS → Graph

::: warning Service Renamed
The PaaS service has been merged into the **Graph** service. All PaaS functionality (deployment management, container orchestration, environment configuration, auto-scaling) is now part of Graph.
:::

Please see the [Graph Service documentation](./graph.md) for the current reference.

The original PaaS documentation files in `infra/graph/docs/` (vision, architecture, data models, SDK, implementation plans, database design) remain the canonical reference for the deployment and orchestration capabilities.
